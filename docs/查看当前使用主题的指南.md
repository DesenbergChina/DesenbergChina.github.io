
jekyll 把主题文件藏在 Ruby Gem 安装目录里

在你的 Jekyll 项目目录运行：

bundle info minimal-mistakes-jekyll

或者：

bundle show minimal-mistakes-jekyll

它会输出类似：

D:/App/RubyGems/gems/minimal-mistakes-jekyll-4.xx.x

然后你直接进入这个目录：

D:\App\RubyGems\gems\minimal-mistakes-jekyll-4.xx.x

里面就能看到：

_includes
_layouts
_sass
assets
_data
